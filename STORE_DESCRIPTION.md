# Chrome Web Store Description

## Short description

Shape browser audio and video with a real-time 10-band equalizer and sound presets.

## Detailed description

Take control of the sound in your browser with Audio Equalizer.

Adjust audio and video in real time with ten graphic EQ bands from 31 Hz to 16 kHz. Use the preamp for overall level control, or start with a built-in Bass, Treble, Vocal, Loudness, Rock, Pop, or Classical preset and fine-tune it to your taste.

Features:

- 10-band graphic equalizer
- Preamp control from -20 dB to +20 dB
- Seven built-in presets plus a custom curve
- Enable or disable processing without stopping playback
- Settings synced across Chrome
- Local processing through the Web Audio API

Audio Equalizer does not make network requests. Your audio stays in the browser.

## Permission disclosure

Audio Equalizer uses the `storage` permission to save equalizer settings. It does not collect or transmit audio, browsing history, or personal information.
